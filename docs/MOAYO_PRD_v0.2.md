> **한 장 요약**  
> MOAYO는 “운동을 오래 하는 것”보다 **“짧게라도 매일 시작하는 것”**에 집중한다. 사용자는 5~15분 단위의 작은 운동 목표를 정하고, 정해진 시간에 울리는 알림을 **운동 미션(스쿼트 횟수, 걸음 수, 타이머, 사진 인증)**으로 해제하며 실천을 자동 기록한다. 쌓인 기록과 매 회차의 체감 난이도를 바탕으로 앱이 **다음 운동을 제안**하고, 사용자는 한 번의 탭으로 다음 계획을 확정한다.  
> v0.2에서는 **“다음 한 번을 확실히 성공시키는 장치”**(사전 리마인드, 미니 전환, 복귀 미션)와 **알림 피로 관리**를 추가했다.

## 02. 배경 및 문제 정의

### 2.1 배경

- 운동을 ‘결심’하는 사람은 많지만, 대부분 처음 2~3주 안에 이탈한다. 목표가 크고(주 5회 1시간), 시작 시점이 모호하며, 진척이 눈에 보이지 않기 때문이다.
- 기존 운동 앱은 기록·루틴 제공에는 강하지만, **“지금 바로 시작하게 만드는 장치”**와 **“지난 기록을 바탕으로 다음을 정해주는 장치”**가 약하다.
- 알라미는 “일어나야만 끌 수 있는 알람”으로 기상이라는 행동을 강제해 큰 호응을 얻었다. 같은 원리를 **운동의 첫 1분**에 적용할 수 있다.

### 2.2 해결할 문제

| 사용자 문제                      | 원인                                      | MOAYO의 접근                                   |
|----------------------------------|-------------------------------------------|------------------------------------------------|
| 운동을 미루고 결국 안 한다       | 시작 시점·분량이 모호, 목표가 부담스러움  | 5~15분 ‘짧은 목표’ + 정해진 시각의 미션 알림   |
| 했는지 안 했는지 기억이 흐릿하다 | 수기 기록이 번거로움                      | 미션 완료 = 자동 기록                          |
| 다음에 뭘, 얼마나 할지 모르겠다  | 기록을 해석해 계획으로 옮기는 과정이 없음 | 체감 난이도 + 달성률 기반 다음 운동 추천       |
| 몇 번 빠지면 포기한다            | ‘전부 아니면 전무’ 사고                   | 스트릭 보호권, ‘1분 미니 미션’, **복귀 미션**  |
| 미션 없는 날 앱을 잊는다 (v0.2)  | 목표 요일 사이의 공백, 다음 미션 망각     | 일요일 리포트의 다음 미션 예고, 사전 리마인드, 선택형 보너스 실천 |

### 2.3 v0.2 진단 요약

- 스트릭은 목표 요일 기준이므로 **목표 요일 사이의 공백 자체는 스트릭을 깨지 않는다.** 진짜 위험은 공백 다음에 오는 **첫 미션을 놓치는 것**이다.
- “스트릭이 짧고 보호권이 소진된 상태”는 최근 한 번 무너졌다는 신호다. 이때 필요한 것은 매일 방문 유도가 아니라 **다음 한 번의 성공**이다.
- 물 마시기·퀴즈 같은 비운동 활동은 North Star를 부풀리고 서비스 정체성을 흐리므로 미션에 포함하지 않는다.

## 03. 벤치마킹: 알라미(Alarmy)

알라미는 국내 스타트업 딜라이트룸이 만든 알람 앱으로, 사진 촬영·수학 문제·흔들기·스쿼트·걸음 수 등 **미션을 수행해야 알람이 꺼지는** 구조가 핵심이다. 기상 후 다시 잠들지 않았는지 확인하는 기상 확인, 아침 루틴, 수면 관련 기능과 프리미엄 구독 모델을 갖추고 있다.

| 알라미 요소         | 알라미에서의 역할                     | MOAYO 적용 방식                                                                                     |
|---------------------|---------------------------------------|-----------------------------------------------------------------------------------------------------|
| 미션 해제           | 몸을 움직여야 알람이 꺼짐 → 기상 강제 | 운동 알림을 **운동 미션 자체**로 해제(스쿼트 10회, 200걸음, 3분 플랭크 타이머 등). 해제 = 실천 인증 |
| 스쿼트·걸음 수 미션 | 센서/카메라로 동작 횟수 인식          | MOAYO의 기본 미션 유형으로 확장(스쿼트, 점핑잭, 걸음, 계단)                                         |
| 사진 미션           | 등록한 장소를 촬영해야 해제           | “운동 장소 인증”(헬스장 입구, 매트 펼친 사진)                                                       |
| 기상 확인           | 해제 후 일정 시간 뒤 재확인           | “진짜 했나?” 재확인 대신 **운동 종료 체크 + 체감 난이도 입력**                                      |
| 아침 루틴           | 기상 직후 할 일 연결                  | 운동 루틴 템플릿(아침 5분 스트레칭 등)                                                              |
| 통계·리포트         | 기상 기록 확인                        | 캘린더 히트맵, 주간 회고 리포트, **다음 운동 추천**(알라미에 없는 차별점)                           |

> **차별점:** 알라미가 “일어나는 순간”을 해결한다면, MOAYO는 **실천 → 기록 → 회고 → 다음 계획**까지 이어지는 습관 루프 전체를 다룬다. 미션은 강제 수단이 아니라 **자동 기록 장치**로도 작동한다.

## 04. 목표 및 성공 지표

### 4.1 제품 목표

1.  사용자가 첫 주에 최소 3회 이상 짧은 운동을 실천하도록 한다.
2.  4주 동안 운동 습관을 유지하는 사용자 비율을 높인다.
3.  사용자가 다음 운동 계획을 스스로 고민하지 않고 1탭으로 확정하게 한다.
4.  (v0.2) 실천이 한 번 끊긴 사용자가 다음 목표일에 다시 시작하도록 한다.

### 4.2 KPI (MVP 출시 후 3개월 목표 — 가설값)

| 구분       | 지표                       | 정의                                                                  | 목표        |
|------------|----------------------------|-----------------------------------------------------------------------|-------------|
| North Star | 주간 실천 횟수             | 활성 사용자 1인당 주간 미션 완료 횟수. **일반·미니·복귀 포함, 보너스 제외** (미니·복귀는 리포트에서 별도 표시) | 주 3회 이상 |
| 활성화     | 첫 미션 완료율             | 가입 후 24시간 내 첫 미션 완료 비율                                   | 60%         |
| 리텐션     | W4 리텐션                  | 가입 4주차에 1회 이상 미션 완료한 비율                                | 30%         |
| 계획       | 추천 수락률                | 제안된 다음 운동을 그대로/일부 수정해 확정한 비율                     | 50%         |
| 습관       | 평균 스트릭                | 활성 사용자의 평균 연속 실천 일수(목표 요일 기준)                     | 7일         |

| 복귀 (v0.2)| 복귀 미션 완료율           | 스트릭이 끊긴 뒤 제안된 복귀 미션의 완료 비율                         | 가설 수립 필요 |

## 05. 타깃 사용자 & 페르소나

**주 타깃:** 운동의 필요성은 느끼지만 꾸준히 하지 못하는 20~30대 직장인·대학생. 홈트레이닝 또는 짧은 외부 활동 선호.

#### PERSONA A · 작심삼일 직장인 지은 (29)

퇴근 후 피곤해서 운동을 미룸. 헬스장 결제 후 3번 감.  
**니즈:** 짧고 확실한 시작 신호  
**MOAYO:** 22시 ‘스쿼트 20회’ 미션 알림

#### PERSONA B · 기록 덕후 대학생 민수 (23)

운동은 하는데 기록이 메모장·사진첩에 흩어져 있음.  
**니즈:** 자동 기록과 성장 그래프  
**MOAYO:** 히트맵·주간 리포트

#### PERSONA C · 복귀 준비 중 수현 (34)

오래 쉬어 어디서부터 해야 할지 모름.  
**니즈:** 무리하지 않는 단계적 계획  
**MOAYO:** 난이도 피드백 기반 점진적 추천, **복귀 미션**

## 06. 핵심 사용자 여정

- **① 목표 설정** — 짧은 목표 + 요일·시간 선택
- **② 리마인드 (v0.2)** — 미션 1시간 전 또는 당일 아침, 지난 기록 기반 메시지
- **③ 미션 알림** — 정해진 시각에 알림, 미션으로만 해제. 시간이 없으면 1분 버전으로 전환
- **④ 실천·인증** — 횟수/타이머/사진 인증 = 자동 기록
- **⑤ 회고** — 체감 난이도 1탭 입력, 기록 확인
- **⑥ 다음 계획** — 추천 운동 확인 → 1탭 확정. 일요일 리포트에서 다음 주 첫 미션 예고

### 대표 시나리오 (Persona A)

1.  지은은 온보딩에서 ‘퇴근 후 10분’ 템플릿을 고르고, 월·수·금 22:00로 설정한다.
2.  수요일 21:00, “지난번 스쿼트는 ‘적당해요’였어요. 오늘 22시, 같은 분량이에요.” 리마인드가 온다.
3.  22:00, 알림이 울린다. 화면에는 “스쿼트 20회를 하면 꺼져요”가 표시되고, 카메라가 동작을 카운트한다.
4.  20회 완료 시 알림이 해제되고, 이어지는 10분 루틴(런지·플랭크)을 타이머로 진행한다.
5.  종료 후 “오늘 어땠나요?”에 `적당해요`를 탭한다. 캘린더에 오늘 칸이 채워지고 스트릭이 5일이 된다.
6.  앱이 다음 운동을 제안하고, 지은은 `좋아요`를 눌러 계획을 확정한다.

### 복귀 시나리오 (v0.2)

1.  지은은 야근으로 금요일 미션을 놓쳤고, 이번 달 보호권은 이미 사용했다. 스트릭이 0이 된다.
2.  일요일 저녁 주간 리포트 마지막에 “월요일 22:00 복귀 미션: 스쿼트 10회”가 예고된다. 지은은 시간을 21:00로 1탭 변경한다.
3.  월요일 21:00, “다시 시작이 제일 어려워요. 오늘은 10회만.” 미션을 완료하고 스트릭이 1부터 다시 시작된다.
4.  다음 미션부터는 8장의 일반 추천 규칙이 다시 적용된다.

## 07. 기능 요구사항

## 08. 다음 운동 추천 로직 (MVP: 규칙 기반)

MVP는 설명 가능한 규칙 기반으로 시작하고, 데이터가 쌓이면 개인화 모델로 고도화한다. 기준 단위는 **최근 3회 실천**이다.

### 8.1 규칙

| 조건                              | 추천 액션                                    | 사용자 메시지 예시                        |
|-----------------------------------|----------------------------------------------|-------------------------------------------|
| 3회 연속 완료 + ‘쉬워요’ 2회 이상 | 분량 +20%                                     | “이제 24회도 충분해요. 올려볼까요?”       |
| 3회 연속 완료 + ‘적당해요’        | 분량 유지 또는 +10%, 운동 종류 1개 추가 제안 | “좋은 페이스예요. 런지를 더해볼까요?”     |
| ‘힘들어요’ 2회 이상               | 분량 −20% 또는 쉬운 대체 운동                | “무리하지 말고 16회로 조정해요.”          |
| 최근 3회 중 2회 이상 미실천       | 분량 −30%, 미니 미션 권유, 시간대 변경 제안  | “22시가 어려웠나봐요. 21시로 바꿔볼까요?” |
| 같은 운동 4주 지속                | 새 운동/챌린지 제안(지루함 방지)             | “2주 플랭크 챌린지 어때요?”               |

> **안전 가드레일:** 1회 증가폭은 최대 +20%로 제한, 같은 부위 운동은 연속일 배정 시 경고, 통증 메모 입력 시 해당 운동 추천 중단 및 휴식 권고.

### 8.2 규칙 적용 기준 (v0.2 제안 — 검토 필요)

v0.1의 ‘+20% (횟수형 +5회, 시간형 +1분)’ 표기는 기준 분량에 따라 +20% 상한과 충돌한다(예: 20회 기준 +5회는 +25%). v0.2에서는 아래 계산식을 제안한다.

- **증감 계산:** 새 분량 = 기준 분량 × (1 + 증감률)을 단위 간격으로 반올림. 단위 간격은 횟수형 1회, 시간형 30초, 걸음형 100보.
- **상한 우선:** 반올림 결과가 +20%를 넘으면 상한 이하가 되도록 내림한다.
- **최소 분량:** 횟수형 5회, 시간형 1분, 걸음형 300보 미만으로 내려가지 않는다.
- **우선순위:** 조건이 동시에 성립하면 다음 순서로 하나만 적용한다.  
  ① 통증 메모(추천 중단) → ② 복귀 미션(8.3) → ③ 2회 이상 미실천 → ④ ‘힘들어요’ 2회 이상 → ⑤ ‘쉬워요’ 2회 이상 → ⑥ ‘적당해요’ → ⑦ 4주 지속
- **신규 사용자:** 실천 기록이 3회 미만이면 분량을 유지하고 추천 메시지만 표시한다.

### 8.3 보호권 · 복귀 미션 규칙 (v0.2)

**보호권**

- 매월 1개 기본 지급(R-04).
- 보너스 실천(R-07) 3회마다 1개 획득.
- 보유 한도 2개. 무료 사용자의 획득분은 월 1개까지(12장 수익 모델과 연계).
- 목표 요일 미션을 놓치면 보유 보호권이 자동 사용되어 스트릭이 유지된다.
- 지급·획득·사용 내역은 원장(ShieldLedger)에 기록한다.

**복귀 미션**

- 스트릭이 0으로 끊긴 직후 **첫 목표일 미션 1회에만** 적용한다.
- 분량: 원래 분량의 50%(8.2절 최소 분량 적용). 예: 런지 20회 → 10회.
- 완료 시 스트릭 1부터 재시작하고, 다음 미션부터 8.1절 규칙을 다시 적용한다.
- 안전 가드레일(통증 메모 시 중단)은 복귀 미션에도 동일하게 적용한다.

## 11. 비기능 요구사항

- **알림 신뢰성:** 예정 시각 ±1분 내 99% 이상 발송. 배터리 최적화·방해금지 모드 예외 설정 가이드 제공(알라미의 핵심 신뢰 요소).
- **알림 피로 관리 (v0.2):** 사용자 1인당 하루 알림 최대 2회(리마인드 1 + 미션 1). 보너스 미션 알림은 기본값 꺼짐. 알림 수신 거부율을 가드레일 지표로 모니터링.
- **성능:** 알림 탭 후 미션 화면 진입 2초 이내, 포즈 인식 카운트 지연 300ms 이내.
- **프라이버시:** 카메라 영상은 기기 내에서만 처리하고 서버 전송·저장하지 않음. 사진 인증 이미지는 사용자 선택 시에만 저장. 개인정보보호법 준수.
- **오프라인:** 네트워크 없이도 미션 수행·기록 가능, 연결 시 동기화.
- **접근성:** 큰 숫자 표시, 음성 카운트, 색만으로 정보 전달하지 않는 히트맵(보너스 실천은 패턴·범례로 구분).
- **안전:** 의학적 조언이 아님을 고지, 통증·건강 이상 시 운동 중단 안내.
